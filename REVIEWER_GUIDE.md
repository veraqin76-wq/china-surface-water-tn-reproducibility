# Running the analyses

Install the Python and R dependencies using the commands in README.md. Run the synthetic example with python run_all.py --mode demo. Configure local analysis input paths in config.manuscript.yml and run python run_all.py --mode manuscript --config config.manuscript.yml for the study data.

FIGURE_TABLE_CODE_MAP.md maps the manuscript figures and tables to analysis scripts and output files. MANUSCRIPT_METHODS_NOTES.md describes the statistical methods. validation/ contains the demonstration run log, software session information and output checks.
